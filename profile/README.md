# Nirvann Applications

We build [Utsav](https://utsavapp.in), a puja and spiritual-services booking platform for devotees in India, and Naxatra.ai, its astrology product.

## What we build

- **Utsav apps and web** — iOS and Android apps on React Native / Expo, the customer website on Next.js, and the internal admin platform. Shipped in Tamil, Telugu, Kannada, Hindi and English.
- **Backend and infrastructure** — Node.js + TypeScript services on GKE, Python / FastAPI services on Cloud Run, Postgres on Cloud SQL, Redis, and AWS Lambda + SQS for payment webhooks.
- **Payments and messaging** — Razorpay, PayU and PhonePe integrations; WhatsApp notifications; AI-assisted multilingual content.

Most of our code is private. Open work from the team lives on [@Prajata22](https://github.com/Prajata22).
