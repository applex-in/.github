We're the team behind [Utsav](https://utsavapp.in). A devotee anywhere in India picks a puja on their phone, a temple performs it in their name, and the video (and often the prasad) finds its way back to them. In Tamil, Telugu, Kannada, Hindi and English, because a blessing should arrive in your own language.

## What we run

- **Two apps and a website** that take bookings, mandates and subscriptions through Razorpay, PayU and PhonePe, and don't flinch when a webhook arrives twice.
- **An admin platform** the ops team lives in all day: puja schedules, video and prasad tracking, settlements, affiliates, WhatsApp campaigns.
- **Services on GCP.** Node.js + TypeScript on GKE, Python + FastAPI on Cloud Run, Postgres on Cloud SQL, Redis, with AWS Lambda + SQS doing the async heavy lifting.
- **A back office that is part human, part agent.** Marketing, SEO, BI, support, ads and push each have a Claude Code agent with its own context and skills, versioned like code. The monthly engineering report writes itself from git. Payout reconciliation is one command. Puja copy ships in five languages with a person approving every word.

## How we work

- Small team, nine repos, two backends that keep identical models, and a shared habit of saying which repo you're in before you touch anything.
- PRDs are written from what the code does today, not from what we wish it did. Docs are markdown in the repo, next to the code.
- Anything that crosses a repo boundary gets its consumers listed before anyone writes a line.
- Every user-facing string is a five-language change. No exceptions.

Almost everything we build is private, so the repositories you can see here are the odd ones out. If you'd like to build this with us, the email on this page reaches the team.
